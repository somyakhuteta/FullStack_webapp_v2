# StudyFlow — Student Productivity Dashboard

Frontend-only student planner built with HTML, CSS and vanilla JavaScript.

## Run
1. Extract the ZIP and open the folder in VS Code.
2. Open `index.html` using Live Server or another local server.

## Files
- `index.html`: page structure, dashboard, forms and dialogs.
- `css/style.css`: responsive design, components and dark theme.
- `js/app.js`: all JavaScript logic, kept under 200 lines.

## Features
Add, edit, complete and delete tasks; search, filter and sort; dashboard statistics; progress and upcoming deadlines; monthly calendar; dark/light theme; browser storage.

## JavaScript concepts
DOM manipulation, event delegation, event listeners, arrays and objects, `map`, `filter`, `sort`, `find`, template literals, arrow functions, conditionals, date handling, JSON, localStorage and form validation.

Data is saved only in the current browser/device. There is no backend or shared database.
